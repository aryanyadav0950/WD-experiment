# 📘 Web Designing Lab – 10 Experiments (HTML, CSS, JS)

This repository contains **10 Web Designing lab experiments** involving **HTML**, **CSS**, and **JavaScript**.  
These experiments include homepage creation, login page, catalogue page, cart page, registration form, JS validation, and CSS designing.
 
--- 
   
## 📑 List of Experiments  

### **1️⃣ Experiment 1 — Homepage Design with Frames**
- Static homepage containing **three frames**
- Top frame: Logo + navigation links (Home, Login, Registration, Catalogue, Cart)
- Left frame: Department links (CSE, ECE, EEE, CIVIL)
- Right frame: Displays description/content

--- 

### **2️⃣ Experiment 2 — Login Page**
- Login form with:
  - Username field  
  - Password field  
  - Submit button  
  - Reset button  
- Organized using table layout

---

### **3️⃣ Experiment 3 — Catalogue Page**
- Displays book details using:
  - Book cover image  
  - Book title  
  - Author  
  - Publisher  
  - Price  
  - “Add to Cart” button  
- Catalogue created for each department

---

### **4️⃣ Experiment 4 — Cart Page**
- Shows books added to cart  
- Displays:
  - Book Name  
  - Price  
  - Quantity  
  - Total Amount  
- Final bill displayed at bottom

---

### **5️⃣ Experiment 5 — Registration Page**
Registration form includes:
1. Name  
2. Password  
3. Email  
4. Phone Number  
5. Gender (radio buttons)  
6. Date of Birth (select dropdowns)  
7. Languages known (checkboxes)  
8. Address (textarea)
